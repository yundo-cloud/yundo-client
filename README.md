## About Yundo

Yundo provides a focused experience for starting and stopping acceleration, choosing a region, selecting an acceleration mode, managing custom access rules, and viewing connection status and traffic information.

## Project Scope

- This repository contains the cross-platform Yundo client.
- Yundo is built as a fork of [Hiddify App](https://github.com/hiddify/hiddify-app) and retains its cross-platform foundation and [sing-box](https://github.com/SagerNet/sing-box) integration.
- Yundo adds its own product experience for accounts, activation, acceleration, region selection, access rules, traffic, and diagnostics.
- Server credentials, private node configuration, and user data are not stored in this repository.
